Get started

  1. Put mcvsc.exe in a folder of its own (for example Documents\mcvsc). It keeps its settings next to itself.
  2. Double-click it, then create a free account or sign in.
  3. Pick a world and press ▶ Play. mcvsc downloads the newest version, starts Minecraft, and uploads the world when you close the game.
  4. On your other PC, do the same with the same email. Your worlds are there.

"Windows protected your PC"

New programs from small developers get this warning from Microsoft Defender SmartScreen until enough people have run them. Click More info, then Run anyway. Only do this for a file you downloaded from this page or the releases page above.

Check the file (optional)

Each release lists the file's SHA-256 checksum. To compare, open PowerShell in the download folder and run:

Get-FileHash .\mcvsc.exe -Algorithm SHA256

The long code it prints must match the one on the releases page exactly.

What it touches on your PC

  • Only the world folders in the game folders you choose (Minecraft Launcher, Prism, CurseForge, Modrinth), and, unless you turn it off, the game settings file next to them (options.txt).
  • Never your mods, resource-pack files, shader-pack files or the game itself.
  • When local changes haven't been uploaded, choose to use the cloud copy or upload your local copy. If you choose the cloud copy, the local copy is saved in a backup folder.
